## VsCode IDE helper for Vectorworks python `vs` module:
VsCode search `typings/` folder for module declaration stub files

### Type annotated [vs.py file](vs.py) in this folder:
Result of automated tool [modernize.py](../tools/modernize.py) run over [stock Vectorworks vs.py](https://github.com/VectorworksDeveloper/SDKExamples/blob/master/VectorworksSDK/SDK2026/SDKLib/Include/vs.py) - to add several IDE-friedly modern features.

Type annotated vs.py file require IDE **python 3.13+**  
It remains hidden from Vectorworks host **python 3.9**, so Vectorworks not yelling at us
